### 安装说明

- Windows：下载 `FrameKit-<version>-Windows-x64.exe` 直接安装。
- macOS：下载对应架构的 DMG（Apple Silicon 选 `arm64`，Intel 选 `x64`）。
- 安装包暂未使用商业代码签名证书，Windows SmartScreen 或 macOS Gatekeeper 可能提示未知开发者。macOS 如被拦截，可在“系统设置 → 隐私与安全性”中仍要打开，或执行 `xattr -dr com.apple.quarantine /Applications/FrameKit.app`。
